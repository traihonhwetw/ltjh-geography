# 臺灣地形拼圖

遊戲固定 24 片，開始前須輸入 5 碼班級座號，例如一年一班 12 號為 `10112`。

入口位於網站導覽列的「其他資源」。

## 啟用成績上傳

目前 `taiwan-landform-jigsaw.html` 的 `SCORE_URL` 留空，網頁會明確顯示練習模式，不會宣稱已上傳。

1. 新增一份 Google 試算表。
2. 在試算表選「擴充功能 → Apps Script」。
3. 把同資料夾的 `score-receiver.gs` 完整貼入編輯器並儲存。
4. 選 `setup` 執行並完成 Google 授權。這會記住目標試算表，建立「成績紀錄」與「最佳成績」兩個工作表。
5. 選「部署 → 新增部署作業 → 網頁應用程式」。執行身分選「我」，存取權選「所有人」。若學校帳戶沒有此選項，需先確認管理員允許的存取方式。
6. 複製結尾為 `/exec` 的部署網址，填入 HTML 的 `const SCORE_URL="";`，再更新網站。
7. 在遊戲完成一次測試，確認顯示「成績已上傳」，試算表也確實新增一列。中斷網路後重傳同一筆紀錄，應維持一列。

更新 Apps Script 後，須透過「管理部署作業」編輯部署，選擇新版本再部署，才會套用新程式。

## 成績格式

「成績紀錄」含上傳時間、遊戲、班級座號、班級、座號、片數、完成秒數、完成時間、紀錄編號。
「最佳成績」依遊戲及班級座號統計最快秒數與挑戰次數。
重傳以紀錄編號在完整紀錄中去重，並使用鎖避免同時寫入兩筆。

部署網址公開可被其他人呼叫，且完成時間由學生裝置提供；這些成績用於課堂遊戲參考。
試算表保持私人即可，學生只需要存取遊戲與接收成績的網頁應用程式。

## 驗證範圍

已透過程式模擬驗證班級座號、24 片生成、吸附、完成計時，以及成功／失敗／重傳回應。
接收程式已驗證輸入檢查、超過 300 筆的重傳去重、寫入失敗後重試及統計公式建立。
實際 Google 授權、部署、跨網域回應與寫入試算表，仍須完成部署後測試。
