# 更換全班拼圖地圖

在電腦瀏覽器開啟老師的成績試算表，重新整理後選「拼圖管理 → 更換全班地圖」。

1. 選擇 JPG／PNG 地圖圖片。
2. 檢查預覽，輸入地圖名稱。
3. 按「套用給全班」。

學生繼續使用原本的拼圖網址。新開啟或按「重新開始」會讀取老師目前設定的地圖；正在進行的挑戰保留原圖，成績記到該版本。

介面下方可切換回原始臺灣地形圖，或最近使用過的地圖。圖片保留在私人試算表的隱藏資料工作表，不會刪除舊地圖或舊成績。不同版本使用不同的統計名稱，例如「世界地形 #1234abcd」，避免同名圖片更新後混算。

老師管理需要使用有試算表編輯權限的帳戶。Google 試算表手機 App 不提供這個自訂選單，請用電腦瀏覽器操作。學生可使用手機或平板玩拼圖。

## 安裝／更新

Apps Script 專案包含 `score-receiver.gs` 與 `map-manager.html`。更新後將現有網頁應用程式部署切換到新版本，保留原有 `/exec` 網址；重新整理成績試算表即可出現「拼圖管理」。

學生頁只讀取公開的地圖圖片與設定，不會讀取試算表成績。教師管理介面從私人試算表開啟，公開 GET／POST 不提供改圖操作。所有管理函式會檢查目前是否在正確的試算表容器執行。

每張地圖固定 24 片，依圖片比例選擇合適的分割方向。圖片讀取失敗時會要求重試，不會讓學生誤用舊圖開始挑戰。
